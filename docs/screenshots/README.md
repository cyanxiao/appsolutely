# Appsolutely screenshots

Real screenshots of Appsolutely running in Raycast. The README cover, `appsolutely.png`, was supplied by the project owner and shows the Home grid over desktop wallpaper. It includes visible application names and icons. Additional 1500×950 examples show only stock macOS apps in temporary demonstration folders. Image metadata was stripped before inclusion without changing the pixels.

| File                                     | Shows                                                                               |
| ---------------------------------------- | ----------------------------------------------------------------------------------- |
| [appsolutely.png](appsolutely.png)       | Owner-supplied README cover showing the Home application grid.                      |
| [launcher.png](launcher.png)             | High-resolution app icons inside the demonstration Applications / Utilities folder. |
| [folder-preview.png](folder-preview.png) | A Utilities folder icon combining six stock macOS apps.                             |
| [search.png](search.png)                 | Global application search, shown with Books.                                        |

The temporary demonstration layout was removed after capture and its apps returned to Home. The owner-supplied cover intentionally shows the visible installed applications.

To embed the main screenshot in the repository's root README:

```md
![Appsolutely — all your apps, organized](docs/screenshots/appsolutely.png)
```

To show the folder preview:

```md
![Appsolutely folder previews](docs/screenshots/folder-preview.png)
```

To share in a GitHub issue, discussion, or release, drag a PNG into GitHub's Markdown editor.

These are native window screenshots for GitHub documentation. For Raycast Store submission, make separate 2000×1250 captures with Raycast's **Capture Window → Save to Metadata** workflow and check the visible content before uploading.
